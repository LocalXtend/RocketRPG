# RocketRPG Release
RocketRPG는 EasyRPG와 JoyPlay에서 영감을 받아 제작한 AI 프로젝트입니다.

Windows(10,11)에서 호환되는 RPGMaker 애뮬레이터를 목표로 하고 있습니다.

쯔꾸르를 플레이하면서 필요했던 것과 있으면 재밌는 것을 추가합니다.

## 버전
> 현재: `1.1.0`
> 다음: `1.1.1`

- RocketRPG는 게임 파일, RTP, RPG Maker 원본 실행 파일을 포함하지 않습니다. 게임과 RTP의 권리는 각 권리자에게 있으며, 각자 정당하게 가진 게임과 공식 경로로 설치한 RTP를 사용해 주세요.
